# ложка хил

Аварийная утилита восстановления системы на C# WinForms — диспетчеризация
процессов, очистка автозагрузки и снятие блокировок после сбоев или заражений.

Утилита предназначена для **восстановления** доступа к системным средствам,
которые нередко блокируются вредоносным ПО (Диспетчер задач, CMD, Regedit,
подмена оболочки Winlogon), и для ручной разгрузки зависшей системы.

## Возможности

### 1. Диспетчер процессов
- Таблица процессов: название, PID, память (МБ), путь к `.exe`.
- Фильтрация по названию в реальном времени.
- Завершение процесса и завершение всего дерева процессов (обход через WMI).
- Экстренная остановка всех несистемных процессов (запущенных не из `C:\Windows\System32`).
- Контекстное меню: «Открыть папку с файлом», «Копировать путь».

### 2. Менеджер автозагрузки
- Чтение веток `Run` и `RunOnce` в `HKCU` и `HKLM`.
- Отображение имени, команды и ветки реестра.
- Удаление записи из автозагрузки.
- Добавление новой записи (в `HKCU\...\Run`).

### 3. Восстановление реестра
- **Сброс блокировок**: удаляет `DisableTaskMgr`, `DisableCMD`,
  `DisableRegistryTools` из `HKCU\...\Policies\System`.
- **Ремонт Winlogon**: восстанавливает `Shell = explorer.exe` и
  `Userinit = C:\Windows\system32\userinit.exe,`.

### 4. Быстрые утилиты
- Перезапуск Проводника.
- Поле «Выполнить команду» (аналог Win+R) и кнопки быстрого запуска
  (taskmgr, cmd, powershell, regedit, control).

## Интерфейс
- Тёмная тема (фон `#0F172A`, акценты `#F59E0B` / `#3B82F6`).
- Окно поверх всех окон по умолчанию (переключается чекбоксом).

## Сборка

```bash
dotnet build LozhkaHil.csproj -c Release
```

Или откройте `LozhkaHil.csproj` в Visual Studio (Windows) и соберите проект.
Целевая платформа — **.NET Framework 4.8**, которая присутствует в стандартных
установках Windows и в среде восстановления (Win RE), поэтому дополнительный
рантайм устанавливать не требуется.

> Требуются права администратора для операций с `HKLM`, ремонта Winlogon и
> завершения чужих процессов. Манифест приложения запрашивает их автоматически.

## Файлы
- `Program.cs` — точка входа и глобальная обработка исключений.
- `FormMain.cs` — вся логика и интерфейс (четыре модуля).
- `app.manifest` — запрос прав администратора и совместимость с ОС.
- `LozhkaHil.csproj` — проект .NET Framework 4.8 (WinForms + WMI).
